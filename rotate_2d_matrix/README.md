# Rotate 2D Matrix

## Description
Ce projet implémente la rotation d'une matrice 2D carrée (n x n) de 90 degrés dans le sens horaire, en place, sans utiliser de module externe.

## Fichier
- `0-rotate_2d_matrix.py`: fonction `rotate_2d_matrix(matrix)` qui modifie la matrice directement.
